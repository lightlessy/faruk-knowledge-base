# Faruk Knowledge Base

ChatGPT tarafından düzenlenen, GitHub Pages üzerinde çalışan kişisel bilgi merkezi.

## Bölümler

- Ana bilgi paneli
- Startup araştırmaları
- Türkiye'ye giriş analizleri
- Gelecekte eklenecek kariyer, finans, yapay zekâ ve matematik notları

## Siteyi açma

GitHub'da **Settings → Pages** bölümüne girin. Kaynak olarak **Deploy from a branch**, dal olarak **main**, klasör olarak **/(root)** seçin ve kaydedin.

Yayın adresi genellikle:

`https://lightlessy.github.io/faruk-knowledge-base/`

## Yeni içerik ekleme

Kök dizindeki `GPT_COMMIT_PROMPT.md` dosyasındaki kısa komutu yeni bir ChatGPT konuşmasına yapıştırın. Model, mevcut yapıyı bozmadan içeriği cilalayıp uygun klasöre eklemelidir.
